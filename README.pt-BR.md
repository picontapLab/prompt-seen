# Prompt Seen

<p align="center"><img src="./src/app/icon.svg" alt="Logotipo do Prompt Seen" width="88" /></p>

<p align="center"><strong>Prompts de imagem com IA testados e modelos reutilizáveis.</strong></p>

O Prompt Seen é uma biblioteca pesquisável de prompts, modelos e resultados gerados que transforma uma ideia visual em uma receita reproduzível.

## Por que usar o Prompt Seen

- Veja o resultado ao lado da receita.
- Entenda como cada frase influencia composição, estilo, assunto e layout.
- Copie prompts ou modelos e adapte-os a um novo projeto.
- Navegue por categoria, estilo, uso, idioma e coleção.
- Preserve modelo, entradas, saídas, créditos e licenças.

## Como contribuir

Inclua o prompt, modelo e versão, requisitos de entrada, arquivo de saída, procedência, atribuição e licença. Execute `npm run content:validate` antes de abrir um pull request.

Consulte [`content/README.md`](content/README.md). O código usa [MIT](LICENSE), prompts e descrições [CC BY 4.0](content/LICENSE), e cada imagem mantém sua licença.
