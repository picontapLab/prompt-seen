# Prompt Seen

<p align="center"><img src="./src/app/icon.svg" alt="Logotipo de Prompt Seen" width="88" /></p>

<p align="center"><strong>Prompts de imágenes de IA probados y plantillas reutilizables.</strong></p>

Prompt Seen es una biblioteca buscable de prompts, plantillas y resultados generados que convierte una idea visual en una receta reproducible.

## Por qué Prompt Seen

- Ver el resultado junto a su receta.
- Entender cómo cada frase afecta composición, estilo, sujeto y diseño.
- Copiar prompts o plantillas y adaptarlos a un proyecto nuevo.
- Explorar por categoría, estilo, uso, idioma y colección.
- Conservar modelo, entradas, salidas, créditos y licencias.

## Cómo contribuir

Incluye el prompt, modelo y versión, requisitos de entrada, archivo de salida, procedencia, atribución y licencia. Ejecuta `npm run content:validate` antes de abrir una pull request.

Consulta [`content/README.md`](content/README.md). El código usa [MIT](LICENSE), los prompts y descripciones [CC BY 4.0](content/LICENSE), y cada imagen conserva su licencia.
