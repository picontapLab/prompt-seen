# Prompt Seen

<p align="center"><img src="./src/app/icon.svg" alt="Logo Prompt Seen" width="88" /></p>

<p align="center"><strong>Prompts d’images IA testés et modèles réutilisables.</strong></p>

Prompt Seen est une bibliothèque de prompts, de modèles et de résultats générés qui transforme une idée visuelle en recette reproductible.

## Pourquoi Prompt Seen

- Voir le résultat à côté de sa recette.
- Comprendre l’effet de chaque formulation sur la composition, le style, le sujet et la mise en page.
- Copier des prompts ou des modèles et les adapter à un nouveau projet.
- Parcourir les contenus par catégorie, style, usage, langue et collection.
- Conserver le modèle, les entrées, les sorties, les crédits et les licences.

## Contribuer

Ajoutez le prompt, le modèle et sa version, les exigences d’entrée, le fichier de sortie, la provenance, l’attribution et la licence. Exécutez `npm run content:validate` avant une pull request.

Le format est décrit dans [`content/README.md`](content/README.md). Le code est sous [MIT](LICENSE), les prompts et descriptions sous [CC BY 4.0](content/LICENSE).
