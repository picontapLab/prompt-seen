# Prompt Seen

<p align="center"><img src="./src/app/icon.svg" alt="Prompt Seen 로고" width="88" /></p>

<p align="center"><strong>검증된 AI 이미지 프롬프트와 재사용 가능한 템플릿.</strong></p>

Prompt Seen은 프롬프트, 템플릿, 실제 생성 결과를 검색할 수 있는 라이브러리입니다. 시각적 아이디어를 반복 가능한 이미지 제작 레시피로 바꿔 줍니다.

## Prompt Seen을 사용하는 이유

- 결과와 정확한 레시피를 함께 확인합니다.
- 문구가 구도, 스타일, 주제, 레이아웃에 미치는 영향을 파악합니다.
- 프롬프트와 템플릿을 새 프로젝트에 재사용합니다.
- 카테고리, 스타일, 용도, 언어, 컬렉션별로 탐색합니다.
- 모델, 입력, 출력, 크레딧, 라이선스를 보존합니다.
