# Prompt Seen

<p align="center"><img src="./src/app/icon.svg" alt="Prompt Seen 標誌" width="88" /></p>

<p align="center"><strong>經過測試的 AI 圖像提示詞與可重複使用模板。</strong></p>

Prompt Seen 是可搜尋的提示詞、模板與實際生成結果資料庫，協助創作者把視覺想法轉成可重複使用的圖像製作配方。

## 為什麼使用 Prompt Seen

- 在同一處查看結果與配方。
- 理解提示詞如何影響構圖、風格、主體與版式。
- 複製提示詞或欄位模板並用於新專案。
- 依類別、風格、用途、語言與合集尋找案例。
- 保留模型、輸入、輸出、來源與授權資訊。

## 如何貢獻

請提交實際使用的提示詞、模型版本、輸入要求、輸出檔案、來源、署名與授權。提交前執行 `npm run content:validate`。

詳細格式見 [`content/README.md`](content/README.md)。程式碼採用 [MIT](LICENSE)，提示詞和描述採用 [CC BY 4.0](content/LICENSE)，圖片依檔案記錄授權。
