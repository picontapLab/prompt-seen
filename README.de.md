# Prompt Seen

<p align="center"><img src="./src/app/icon.svg" alt="Prompt Seen Logo" width="88" /></p>

<p align="center"><strong>Getestete KI-Bild-Prompts und wiederverwendbare Vorlagen.</strong></p>

Prompt Seen ist eine durchsuchbare Bibliothek aus Prompts, Vorlagen und generierten Ergebnissen. Sie macht aus einer visuellen Idee ein reproduzierbares Bildrezept.

## Warum Prompt Seen

- Ergebnis und Rezept gemeinsam prüfen.
- Den Einfluss einzelner Formulierungen auf Komposition, Stil, Motiv und Layout verstehen.
- Prompts und Vorlagen für neue Projekte anpassen.
- Nach Kategorie, Stil, Anwendungsfall, Sprache und Sammlung suchen.
- Modell, Eingaben, Ausgaben, Credits und Lizenzen nachvollziehbar halten.

Bitte Prompt, Modell und Version, Eingabeanforderungen, Ausgabedatei, Herkunft, Attribution und Lizenz angeben. Vor einem Pull Request `npm run content:validate` ausführen.
