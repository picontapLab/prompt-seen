# Prompt Seen

<p align="center"><img src="./src/app/icon.svg" alt="Prompt Seen 标志" width="88" /></p>

<p align="center"><strong>经过测试的 AI 图像提示词与可复用模板。</strong></p>

Prompt Seen 是一个可搜索的提示词、模板和真实生成结果库，帮助创作者把视觉想法变成可复用的图像制作配方。

<p align="center"><strong>语言：</strong> <a href="./README.md">English</a> · <a href="./README.zh-CN.md">简体中文</a> · <a href="./README.zh-TW.md">繁體中文</a> · <a href="./README.es.md">Español</a> · <a href="./README.pt-BR.md">Português</a> · <a href="./README.ja.md">日本語</a> · <a href="./README.ko.md">한국어</a> · <a href="./README.de.md">Deutsch</a> · <a href="./README.fr.md">Français</a></p>

## 为什么使用 Prompt Seen

- 在同一处查看结果和配方。
- 理解提示词如何影响构图、风格、主体和版式。
- 复制提示词或字段模板并用于新项目。
- 按类别、风格、用途、语言和合集查找案例。
- 保留模型、输入、输出、来源和许可证信息。

查看[测试方法](https://promptseen.dev/zh-hans/about/#testing-method)，浏览[商品](https://promptseen.dev/zh-hans/categories/product/)、[海报](https://promptseen.dev/zh-hans/categories/poster/)、[人像](https://promptseen.dev/zh-hans/categories/portrait/)、[社媒发布](https://promptseen.dev/zh-hans/use-cases/social-post/)和[包装](https://promptseen.dev/zh-hans/use-cases/packaging/)主题，或下载[简体中文](https://promptseen.dev/generated/datasets/v2/zh-Hans.json)和[英语](https://promptseen.dev/generated/datasets/v2/en.json)数据集。
