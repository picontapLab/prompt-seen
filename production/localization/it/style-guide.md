# Italian editorial guide

Use standard written Italian, sentence case and concise second-person singular instructions. Buttons use the imperative: Copia, Scarica, Reimposta. Write prompt and poster unchanged in the plural; distinguish modello di prompt from modello di IA.

Preserve accents (including È and perché), use typographic apostrophes in prose and «…» for quotations. Do not add French spacing before punctuation. Never normalize or smart-quote Prompt bodies, identifiers, user input, URLs or code.

Translate the actual source language identified by the localization report. Preserve uncertainty, input requirements, untested variations, licensing, exact model identifiers and the distinction between provider-generated frames and locally composed GIFs. Page language does not change the original Prompt language.

Review complete source/target pairs before approving their exact hashes. Identify AI reviews as AI; translation, language review, asset inspection and browser verification are separate evidence. Reuse media-fact evidence only for the same asset hash and same factual scope.

Numbers and dates use formatLocale and the existing UTC formatter. UI messages retain every ICU argument and rich-text tag; test 0, 1, 2, 21, 1.5 and 1000000. Do not localize serialized numeric values or template constraints.
