# 日本語の表記・翻訳方針

状態：運用案。既存の翻訳・画像説明を一括で承認するものではありません。

説明文は「です・ます」調に統一し、短い文で操作と結果を説明します。見出しには内容が分かる名詞句または自然な疑問文を使います。ボタンは「コピー」「ダウンロード」「リセット」「保存」など、実行する操作を端的に示します。

句読点は「、」「。」、引用には「」を使います。数値、日付、バージョン、比率、モデル名は元データを保ちます。技術識別子、URL、作者名、ブランド名は翻訳しません。ICU の引数名とタグ、Markdown のリンク先、Figure の asset ID は変更しません。

「プロンプト」は実際にモデルへ渡す本文を指します。「説明」「入力ガイド」はページ上の案内です。ページが日本語でも、コピー対象のプロンプトが日本語とは限りません。本文、テンプレートの既定値、選択肢の実際の出力値、ユーザーが入力した文字列を翻訳しません。

入力ガイドは、必要な画像の種類・枚数・各スロットの役割を明示します。「参照画像」を生成結果と混同しません。画像の代替テキストは画像の意味や役割を説明し、ファイル名や「画像」だけで済ませません。生成結果の確認事項は、実際に記録された観察の範囲に限定します。

出典の説明では、投稿全体の指標と個別画像の指標、原文を取得できた場合と独自に調整した場合を区別します。記録のない検証、モデルの厳密なスナップショット、利用量、許諾を推測して追記しません。ライセンス名・リンク・適用範囲は原文と照合します。

各バッチの審校では、自然な日本語、用語の統一、操作の意味、入力条件、出典・ライセンスの主張、画像説明を確認します。`reviews.json` は実際に完了した審校だけを記録します。機械翻訳の生成と審校は別工程です。
