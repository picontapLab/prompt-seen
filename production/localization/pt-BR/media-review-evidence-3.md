It is not a claim of real-time animation playback, browser behavior, human/native-speaker review, scientific certification, historical source verification or newly generated images. Generic source descriptions remain generic rather than inventing unavailable identity or model information. The original assets and source text were not modified. Existing historical generation/review claims were evaluated for translation fidelity, not re-certified wholesale. Browser layout, keyboard interaction and release checks remain separate.
