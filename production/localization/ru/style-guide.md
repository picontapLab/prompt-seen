# Russian editorial rules

Locale: `ru`, language-level Russian for readers in any region. Specification:
[Russian localization](../../../docs/russian-localization-spec.md).

- Use neutral written Russian and polite lowercase «вы». Buttons use infinitives.
- Use sentence case, real ё and й, «outer quotes» and „inner quotes“ in prose.
  Search folds ё/е, but text, input values and copied Prompts preserve original spelling.
- Prompt: «промпт»; template: «шаблон промпта»; AI model: «модель ИИ»;
  collection: «подборка»; topic: «тема»; product photography: «предметная съёмка».
- Use ICU one/few/many/other in complete sentences. Check 0, 1, 2, 4, 5,
  11–14, 21, 22, 25, 101, 111, and the decimal formatting branch.
- Original Prompt bodies, quoted image lettering, IDs, model names, parameters,
  URLs, licences and user inputs are protected. Explain them without changing them.
- Translate source claims with their uncertainty. A recorded output is not proof
  of an exact provider snapshot or of a successful Russian-language generation.
- Inspect assets for alt text; reusable prior evidence must match the asset hash
  and the actual fact being described. GIF motion needs frame/animation evidence.
- AI translation and AI review are recorded explicitly. No native-speaker or human
  certification is implied. Generating a candidate does not approve it.
- Keep English single-key C/S as Latin characters in keyboard help; never turn
  Cyrillic с into Copy. Search Ctrl/Cmd+K also accepts the physical KeyK code.

Preparation is complete/fingerprint/source-only with production disabled. Preview
and release must pass the stage gates in the specification.
