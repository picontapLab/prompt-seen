# Español: guía editorial

Usamos español estándar, sin variantes regionales de página. Nos dirigimos al lector con «tú». Las instrucciones son breves y concretas; los botones usan infinitivos: Copiar, Descargar, Restablecer. Los títulos siguen la puntuación natural de una frase. Conservamos á, é, í, ó, ú, ü, ñ y los signos ¿ ¡. Los sinónimos regionales se mantienen como alias de búsqueda.

Un prompt es el texto para el modelo; una plantilla lo genera a partir de parámetros; una colección reúne obras. «Retrato» describe un sujeto y «vertical» un formato. Una explicación en español no implica que el prompt copiable esté traducido. Cada prompt conserva su idioma original y sus bytes.

Las variables ICU, las etiquetas, los nombres de marca y modelo, los enlaces, el código y el texto exigido dentro de una imagen se conservan. Los formatos de fecha y número usan el módulo existente. Las etiquetas y ayudas de una plantilla se traducen; los valores predeterminados, las opciones, los límites y el orden de entrada no se cambian.

Los textos alternativos describen la imagen real, no lo que el prompt pide. Se abren las imágenes y se comprueba la secuencia completa de una animación antes de aprobar su descripción. Las imágenes de referencia y los resultados generados se distinguen. Una observación histórica sigue siendo una observación histórica, sin convertirla en una garantía ni en una prueba repetida.

La revisión textual, visual y de interacción se registra por separado. Los registros de aprobación identifican a la IA cuando corresponda y se vinculan a los hashes reales del texto revisado. Mantener intactos la atribución, las licencias, las advertencias de adaptación independiente y los datos desconocidos. Una excepción para una marca sin traducir necesita un motivo específico para el campo; no aprueba prosa sin traducir.

La revisión en navegador debe cubrir ambas apariencias, teclado y los anchos del spec. El zoom real y la remaquetación equivalente se registran por separado. Esta guía no certifica una revisión visual ni una validación de producción.
