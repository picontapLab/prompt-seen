# 한국어 편집 지침

표준 한국어로 짧고 구체적으로 씁니다. 설명은 일관된 존댓말로, 사용 지침은 “입력하세요”, “확인하세요”처럼 씁니다. 버튼에는 “복사”, “저장”, “초기화”처럼 간결한 동작을 표시합니다. 화면 설명의 한국어 번역과 모델에 전달하는 원문 프롬프트를 구분합니다.

동적 값에는 고정 조사를 붙이지 않고 “사용 모델: {model}”처럼 문장을 구성합니다. ICU 인수, 태그와 업무상 의미가 있는 수량 분기를 보존합니다. 날짜와 수는 기존 로케일 포매터로 표시합니다. 검색용 붙여쓰기나 외래어 변형 때문에 화면 문구를 부자연스럽게 바꾸지 않습니다.

페이지는 보고서가 지정한 실제 원문에서 번역합니다. 참조 이미지는 입력이며 생성 이미지는 출력입니다. 이미지의 실제 모습을 확인한 뒤 대체 텍스트와 설명을 검토합니다. 파일명이나 프롬프트만 보고 보이지 않는 사실을 추가하지 않습니다.

정확한 모델 버전이 알려지지 않았다면 모른다고 씁니다. 개별 실행에서 관찰한 결과를 모델의 일반적인 성능 보장으로 바꾸지 않습니다. 브랜드, 모델명, 코드, 주소, 라이선스, 프롬프트 원문, 입력값과 화면 안에 의도적으로 넣은 글자는 그대로 유지합니다.

번역 생성과 검토는 별도 단계입니다. 실제로 수행한 검토만 출처와 번역의 지문에 연결해 기록합니다. AI 검토는 AI라고 표시하며 원어민 검토나 실기기 입력법 시험으로 표현하지 않습니다. 언어, 이미지와 브라우저 증거를 구분하고 미완료 항목은 pending으로 남깁니다.

참조 이미지 슬롯의 “Subject”는 사진에 나타난 “대상”으로 옮깁니다. 주제나 소재를 입력하는 필드의 “Subject”는 “주제”로 옮깁니다. 문맥을 확인하고 일괄 치환하지 않습니다.
