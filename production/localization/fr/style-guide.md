# Français

Français écrit général, sans variante régionale dupliquée. Adressez-vous au lecteur avec « vous ». Les boutons utilisent l’infinitif et les titres la casse de phrase. Distinguez le modèle de prompt réutilisable du modèle d’IA. Un portrait est un sujet ; vertical est un format.

Conservez les accents, les ligatures œ/æ et l’apostrophe typographique ’ dans les explications. Utilisez U+00A0 avant le deux-points et le pourcentage et à l’intérieur de « … », U+202F avant ; ? !. Ne transformez jamais le code, les URL, les variables, le prompt original ni les valeurs saisies. Intl gère les nombres, avec des chiffres latins et les dates en UTC. Pour les résultats vides, utilisez une branche ICU =0 explicite.

Traduisez les titres, résumés, explications, champs, textes alternatifs et métadonnées SEO. Conservez les noms de modèles, leurs versions réellement enregistrées, les marques, identifiants, licences, paramètres, valeurs d’énumération et textes littéraux demandés dans les images. La traduction de l’interface ne certifie pas un prompt traduit. N’ajoutez aucune garantie à la licence ou aux faits de génération.

Lisez la langue source déclarée, y compris le chinois simplifié ; une traduction allemande ou espagnole n’est pas une nouvelle source. Vérifiez l’image réelle avant d’approuver sa description ; une animation exige de vérifier le mouvement ou des images successives suffisantes. Une preuve existante ne se réutilise qu’avec le même hash d’asset et le même périmètre factuel.

Séparez génération de traduction, révision linguistique, vérification des médias et test des interactions. Identifiez toute révision par IA comme telle. Les règles de recherche ignorent certains accents, ligatures et préfixes élidés, mais le texte visible garde son orthographe. Une photographie quelconque ne devient pas une photographie de produit.
