# Arabic editorial and display contract

Use Modern Standard Arabic with short, direct instructions. Prompt is أمر نصي (أمر in established context), template is قالب, and AI model is نموذج ذكاء اصطناعي. Preserve brand names, model IDs, technical values, source limitations and licences. Do not infer geography, religion or image content from the language.

Use Arabic punctuation in explanatory prose. Do not convert punctuation, digits, whitespace, variables or strings in original Prompts, template values or user input. Avoid decorative tatweel and presentation-form characters. Never insert bidi control characters to fix a layout; HTML direction and isolation provide the boundary.

Use the six Arabic cardinal plural categories or a grammatically neutral count label. The formatter explicitly selects Gregorian dates, UTC and Latin display digits; search also accepts Arabic-Indic and Eastern Arabic-Indic digits. Search normalization must never replace the displayed text.

The page and its controls are RTL. Each explanatory or Prompt block keeps its actual language. Unknown user text uses automatic direction; known technical values use LTR isolation. Images, GIFs, coordinates, ratios and original Prompt instructions are never mirrored or translated by a locale switch.

Use the delivered IBM Plex Sans Arabic 400/500/600 faces, zero letter spacing, body leading 1.8 and display leading 1.35. Test connected letters and diacritics as well as mixed Latin text. Unknown input uses lang="" and must still have an Arabic font fallback.

Every translation needs a current source/target fingerprint review. AI linguistic review is labelled AI and is not human/native-speaker acceptance. Media descriptions need visual inspection. First public release additionally requires the human Arabic and screen-reader review specified in the spec. Keep ar disabled until all content and acceptance gates pass.
