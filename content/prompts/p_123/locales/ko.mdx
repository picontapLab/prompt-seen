## 사용 방법

제품 사진 한 장을 업로드하고 팔레트와 장면 주제를 정확히 아홉 개 제공하세요.

모든 칸에서 제품 실루엣, 뚜껑과 라벨을 일관되게 유지하세요.

## 기록된 결과

두 테스트 이미지는 고객의 제품 사진이 아닌 동일한 합성 PINE 병 참조 이미지를 사용합니다. 기본 실행은 세이지 그린, 아이보리와 브러시드 실버를 사용하며 대안 실행은 팔레트와 아홉 장면의 설명을 바꿉니다. 아래의 각 이미지는 자체 입력, 결과와 제출한 프롬프트를 짝지어 보여 줍니다.

두 결과 모두 아홉 칸으로 구성됩니다. 제품이 보이는 시점에서는 병, 은색 뚜껑과 PINE 글자를 알아볼 수 있으며 소재와 물감의 클로즈업에는 병 전체가 나오지 않습니다. 이는 이 두 결과에서 관찰한 내용이며 다른 패키지나 작은 라벨 글자에 대한 보장은 아닙니다.

## 생성 증거와 한계

[기본 실행 기록](https://github.com/picontapLab/prompt-seen/blob/89395feb8e5fda7419aa3f5d2594df8a71fb3363/content/examples/x_168/run.yaml)과 [대안 실행 기록](https://github.com/picontapLab/prompt-seen/blob/89395feb8e5fda7419aa3f5d2594df8a71fb3363/content/examples/x_196/run.yaml)은 프롬프트 해시, 순서가 지정된 참조 ID와 결과 ID를 보존합니다. 두 실행 모두 2026년 10월 29일 내장 이미지 도구를 사용한 것으로 기록되었습니다.

GPT Image 2.5라는 표시 버전은 [프로젝트 소유자의 버전 표기](https://github.com/picontapLab/prompt-seen/blob/89395feb8e5fda7419aa3f5d2594df8a71fb3363/production/model-version-annotation-2026-11-05.json)에 따릅니다. 도구는 정확한 API 모델 ID를 반환하지 않았습니다. 시드, 샘플링 설정과 품질 설정은 기록하지 않았으며, 비어 있는 매개변수 기록만으로 기본값을 확정할 수 없습니다. 프롬프트를 재사용해도 동일한 픽셀이 보장되지는 않습니다.

[캠페인 템플릿](template:t_017)으로 팔레트나 장면을 바꾸세요. 프롬프트나 제품 사진을 바꾸면 아직 테스트하지 않은 변형이 됩니다. 결과를 사용하기 전에 칸 수, 제품 형태와 글자를 자신의 참조 이미지와 비교하세요.
