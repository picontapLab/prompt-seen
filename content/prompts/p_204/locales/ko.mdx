## 사용 방법

이 이미지를 만들 때 사용한 프롬프트를 그대로 복사하세요. 대상을 바꾸면 아직 테스트하지 않은 새 변형이 됩니다. 생성 전에 실행 기록에 표시된 합성 참조 이미지를 정해진 순서대로 업로드하세요.

## 관찰된 결과

전신 핀 하나에 반짝이는 금속 테두리와 선명한 에나멜을 사용하여 참조의 머리 모양, 안경과 옷 색상을 유지했습니다.

## 출처

제공된 디자인 프롬프트 모음의 사례 56에서 착안해 독립적으로 재구성했습니다. [출처](https://github.com/jamez-bondos/awesome-gpt4o-images/blob/main/README_en.md). 이 이미지는 GPT Image 2.5로 생성했습니다. 도구는 정확한 API 모델 ID를 반환하지 않았습니다.
