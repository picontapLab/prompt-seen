## 사용 방법

입력 이미지를 추가하지 않고 전체 원본 프롬프트를 붙여 넣으세요.

## 출처와 생성

[@NovaXCode의 원본 프롬프트](https://x.com/NovaXCode/status/2118383239392075848). 프롬프트는 두 언어 버전 모두 원래 언어를 유지합니다. 작성자는 출처 작품을 Image 2.6으로 명시합니다. 이번 새 예시는 GPT Image로 생성했으며 도구는 정확한 모델 버전을 반환하지 않았습니다. 출처 게시물의 반응 수치는 별도로 기록합니다. 출처 게시물은 모델을 비교하지만 이 페이지는 모델 비교가 아닌 새로운 GPT Image 결과 하나를 보여 줍니다.
