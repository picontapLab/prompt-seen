## How to use

Use the exact recorded prompt. No reference image is required. Changes to the prompt or inputs create an untested variant.

## Observed result

Six-frame office reaction progresses from hope to shock, crying and wiping tears, then returns to the starting pose. Falling chart stays visible. Encoded as a 1.8-second looping GIF from the generated sheet.

## GIF assembly

The model generated a 3-column by 2-row PNG sprite sheet. Crop equal cells in row-major order and encode six frames at 300 ms per frame with infinite looping. The resulting GIF is 512 × 512 pixels and 1.8 seconds per cycle. No interpolation was added. This is a composed animation, not a native GIF returned by the model.

## Source and generation

The source provides an original prompt; this production uses the separately recorded working prompt. [Source](https://openai.com/index/introducing-images-2-6/#animate-your-ideas-with-gifs). Source-post engagement does not measure this newly generated example.

Generated with GPT Image 2.6. All reference images used here were generated for this project.
