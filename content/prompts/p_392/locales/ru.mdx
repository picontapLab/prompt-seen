## Как использовать

Загрузите синтетическое эталонное изображение проекта и используйте записанный промпт без изменений.

## Наблюдаемый результат

Синемаграф двигает только один небольшой природный элемент: пар, воду, дождь или листья. Создано с GPT Image 2.6 через OpenAI Image API как нативный анимированный GIF из 9 кадров по 200 мс на кадр.

## Источник и генерация

Этот пример является воспроизведением или адаптацией Prompt Seen на основе указанного публичного источника. Взаимодействия источника не измеряют этот новый результат.
