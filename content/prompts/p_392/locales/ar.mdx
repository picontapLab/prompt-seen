## طريقة الاستخدام

ارفع الصورة المرجعية الاصطناعية للمشروع ثم استخدم النص المسجل كما هو.

## النتيجة الملحوظة

تحرك السينماغراف عنصراً طبيعياً صغيراً فقط مثل البخار أو الماء أو المطر أو الأوراق. تم التوليد باستخدام GPT Image 2.6 عبر OpenAI Image API كصورة GIF متحركة أصلية من 9 إطاراً، بمدة 200 مللي ثانية لكل إطار.

## المصدر والتوليد

هذه الحالة إعادة إنتاج أو تكييف من Prompt Seen استناداً إلى المصدر العام المرتبط. تفاعلات المصدر لا تقيس هذه النتيجة الجديدة.
