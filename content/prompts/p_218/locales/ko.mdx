## 사용 방법

기록된 프롬프트를 그대로 사용하고 표시된 원본 참조 자산을 순서대로 입력하세요. 프롬프트나 입력을 바꾸면 아직 테스트하지 않은 변형이 됩니다.

원본 합성 방 사진을 먼저, 별도의 빨간 원 표시 오버레이를 다음에 업로드하세요. 오버레이는 꽃병을 지정하며 생성 결과가 아닙니다. 기록된 작업용 프롬프트는 중국어이며 여기에서도 변경하지 않았습니다. 영어로 번역하면 새롭고 아직 테스트하지 않은 프롬프트가 됩니다.

## 관찰된 결과

화병이 크림색에서 코발트색으로 바뀌었고 빨간 표시가 제거되었습니다. 물주전자, 마른 줄기, 타일과 창문은 시각적으로 일관되며, 새 유약은 더 광택이 납니다.

## 생성 증거와 한계

[실행 기록](https://github.com/picontapLab/prompt-seen/blob/89395feb8e5fda7419aa3f5d2594df8a71fb3363/content/examples/x_282/run.yaml)은 프롬프트 해시를 순서대로 입력 a_373, a_374 및 출력 a_372에 연결합니다. [생성 영수증](https://github.com/picontapLab/prompt-seen/blob/89395feb8e5fda7419aa3f5d2594df8a71fb3363/production/gpt-image-26-2026-11/audit/S10.json)은 입력과 출력 해시를 보존합니다. 타임스탬프는 UTC 기준 11월 5일이며, 이는 해당 실행에 표시된 로스앤젤레스 기준 11월 4일에 해당합니다.

GPT Image 2.6은 [프로젝트 소유자가 명시한 버전](https://github.com/picontapLab/prompt-seen/blob/89395feb8e5fda7419aa3f5d2594df8a71fb3363/production/model-version-annotation-2026-11-05.json)입니다. 도구는 정확한 API 모델 ID를 반환하지 않았으며 시드, 샘플링과 품질 설정은 기록되지 않았습니다. 이 출력 하나는 색이 바뀌고 표면의 광택이 강해진 모습을 보여 줄 뿐, 색상 편집이 모든 반사나 픽셀을 유지한다는 증거는 아닙니다. 자신의 이미지에 적용할 때는 소재 마감과 주변 물체를 확인하세요.

## 출처와 생성

출처에는 원본 프롬프트가 있으며 이번 제작은 별도로 기록한 작업용 프롬프트를 사용합니다. [출처](https://developers.openai.com/api/docs/guides/image-prompting#guide-an-edit-with-markup). 출처 게시물의 반응 수치는 이번에 새로 생성한 예시를 평가한 것이 아닙니다.

GPT Image 2.6으로 생성했습니다. 여기 사용된 모든 참조 이미지는 이 프로젝트를 위해 생성했습니다.
