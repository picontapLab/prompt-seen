## How to use

Upload a high-contrast portrait guide and use a tool capable of strong reference or structure conditioning.

Inspect both full size and thumbnail. Plain text alone is insufficient; our recorded workflow supplies the guide image directly.

## Recorded result

The example was generated with the built-in image tool. Its exact model ID was not returned. The recorded run contains the submitted prompt and ordered inputs.

## Result limitation

The current result uses the supplied silhouette with the built-in image tool, not ControlNet. Individual flower beds, trees and paths form an oblique garden plane, while a thumbnail reveals the face. The face can still be noticed at full size; subtlety and likeness vary across generations. The earlier, stronger face-shaped result remains in the run history.
