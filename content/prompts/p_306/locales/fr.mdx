## Utilisation

Importez l’image de référence générée pour le projet dans l’ordre affiché (R15), puis utilisez le prompt adapté complet.

Réutilisez la planche GPT Image 2.6 archivée et rééchantillonnez l’action sur neuf images. Pour les sources à huit poses, une pose maintenue est répartie sur deux images encodées sans ajouter de nouvelle pose ; pour les séquences plus longues, sélectionnez neuf poses dans l’ordre chronologique. Conservez la durée totale et les réglages de boucle. Les petites cellules sources sont agrandies pour l’affichage sans ajout de détails. Le GIF est assemblé localement ; l’outil d’image a renvoyé un PNG statique. La planche source, les découpes exactes, les durées et l’image d’aperçu tirée de la première image sont conservées dans les archives de la campagne.

## Résultat et limites

9 images, 2 secondes, 443 × 443 px ; répétition infinie. Planche d’images GPT Image 2.6 et encodage GIF local.

Toutes les séquences de neuf images ont été examinées dans quatre planches-contact : ordre des actions, identité, légendes et poses finales conservés. Ce résultat réutilise les pixels sources GPT Image 2.6 archivés ; aucun nouvel appel au fournisseur. Une pose maintenue est répartie sur deux images : huit poses sources distinctes, neuf images encodées. La durée totale et le nombre de lectures sont conservés. Examen de la source d’origine (les nombres d’images ne concernent que la source) : Huit images dessinées montrent dans l’ordre les paupières ouvertes, mi-closes, fermées puis rouvertes. Visage, vêtements et cadrage restent cohérents avec de légères variations de dessin entre les images. Encodé en boucle infinie de deux secondes ; métadonnées réelles du GIF vérifiées. C’est une adaptation à partir d’une planche d’images, pas une sortie GIF native du prompt source.
