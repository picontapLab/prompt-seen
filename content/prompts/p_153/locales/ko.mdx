## 사용 방법

이 이미지를 만들 때 사용한 프롬프트를 그대로 복사하세요. 대상을 바꾸면 아직 테스트하지 않은 새 변형이 됩니다. 생성 전에 실행 기록에 표시된 합성 참조 이미지를 정해진 순서대로 업로드하세요.

## 관찰된 결과

위쪽에서 비스듬히 본 시점에서 조형적인 뚜껑 윗면과 속이 빈 옆 손잡이가 드러납니다. 참조의 점박이 도자기와 금색 띠를 유지했습니다.

## 생성 증거와 한계

이 예시는 합성한 도자기 향수병 참조 이미지 하나를 사용합니다. 새로운 패키지 디자인이 아니라 이음매 없는 흰 배경에서 새로운 카메라 각도로 보여 달라고 요청합니다. 테스트 이미지에 표시된 참조 이미지와 뚜껑, 목 부분의 링, 손잡이 구멍과 몸체 비율을 비교하세요. 출력은 생성된 해석이며 이 예시 하나로 보이지 않는 측면의 정확한 형태를 입증할 수는 없습니다.

[10월 30일 실행 기록](https://github.com/picontapLab/prompt-seen/blob/89395feb8e5fda7419aa3f5d2594df8a71fb3363/content/examples/x_269/run.yaml)은 제출한 프롬프트 해시, 참조 a_359와 출력 a_358을 템플릿 v1에 연결합니다. GPT Image 2.5는 [프로젝트 소유자가 명시한 버전](https://github.com/picontapLab/prompt-seen/blob/89395feb8e5fda7419aa3f5d2594df8a71fb3363/production/model-version-annotation-2026-11-05.json)이며 생성 도구는 정확한 API 모델 ID를 반환하지 않았습니다. 시드, 샘플링과 품질 설정은 기록되지 않았습니다. 이 프롬프트를 재사용해도 동일한 픽셀이나 다른 제품의 정확한 시점이 보장되지는 않습니다.
