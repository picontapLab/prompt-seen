## Utilisation

Importez l’image de référence générée pour le projet dans l’ordre affiché (R16), puis utilisez le prompt adapté complet.

Réutilisez la planche GPT Image archivée et rééchantillonnez l’action sur neuf images. Pour les sources à huit poses, une pose maintenue est répartie sur deux images encodées sans ajouter de nouvelle pose ; pour les séquences plus longues, sélectionnez neuf poses dans l’ordre chronologique. Conservez la durée totale et les réglages de boucle. Les petites cellules sources sont agrandies pour l’affichage sans ajout de détails. Le GIF est assemblé localement ; l’outil d’image a renvoyé un PNG statique. La planche source, les découpes exactes, les durées et l’affiche de la première image sont conservées dans les archives de la campagne.

## Résultat et limites

9 images, 2 secondes, 362 × 362 px ; une seule lecture. Planche d’images GPT Image et encodage GIF local.

Toutes les séquences de neuf images ont été examinées dans quatre planches-contact : ordre des actions, identité, légendes et poses finales conservés. Ce résultat réutilise les pixels sources GPT Image archivés ; aucun nouvel appel au fournisseur. Une pose maintenue est répartie sur deux images : huit poses sources distinctes, neuf images encodées. La durée totale et le nombre de lectures sont conservés. Examen de la source d’origine (les nombres d’images ne concernent que la source) : Huit premières cellules sélectionnées : le chat regarde la caméra, fait un clin d’œil, puis un chapeau vert marqué Robin tombe et se pose. Quatre dernières cellules écartées parce que le chat saute ou disparaît. Le GIF final de huit images est lu une fois en deux secondes ; aucune fausse revendication de boucle sans raccord. Robin est lisible sur le chapeau posé.
