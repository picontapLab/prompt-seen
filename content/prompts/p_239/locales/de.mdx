## So verwendest du den Prompt

Lade ein klares Schneemannbild hoch. Dieses Beispiel verwendet einen von Prompt Seen generierten Schneemann.

## Quelle und Generierung

[Originalprompt von @Goodmanprotocol](https://x.com/Goodmanprotocol/status/2118193088128745875). Der Prompt bleibt in beiden Sprachfassungen in seiner Originalsprache. Der Autor bezeichnet das Quellwerk als Image 2.6. Dieses Beispiel entstand mit GPT Image 2.6. Das Werkzeug lieferte keine genaue API-Modell-ID. Interaktionen mit dem Quellbeitrag werden separat dokumentiert.
