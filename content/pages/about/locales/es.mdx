Prompt Seen es una biblioteca de prompts de imágenes que puedes leer, copiar y adaptar. Cada entrada muestra la imagen que produjo y señala qué frases del prompt cambiaron cada aspecto.

## ¿Cómo se prueban los prompts?

Cada prompt se ejecuta con un modelo, una fecha y unos parámetros registrados. El registro se conserva junto al prompt como ejecución de ejemplo, y la página muestra cuándo se probó por última vez. Las entradas sin una ejecución registrada se marcan como «Sin verificar».

## ¿Qué son las entradas de ejemplo?

Las 101 imágenes de contenido se generaron con GPT Image usando los prompts que aparecen en sus páginas. Cada una tiene una ejecución registrada y una revisión visual. La herramienta integrada no expone la versión exacta del modelo ni el consumo. Las imágenes descargables a tamaño completo pueden usar una conversión de formato sin pérdidas; los tamaños de visualización se comprimen por separado. Las ejecuciones anteriores de ejemplos procedurales están archivadas.

## ¿Cómo puedo comunicar un problema?

Abre una incidencia en el repositorio del proyecto si encuentras información incorrecta, páginas que no funcionan o un problema de licencia.
