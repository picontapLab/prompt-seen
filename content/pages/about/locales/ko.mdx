Prompt Seen은 이미지 프롬프트와 재사용 가능한 템플릿을 생성 결과와 함께 제공하는 라이브러리입니다.

## 프롬프트는 어떻게 테스트하나요?

라이브러리의 모든 사례는 GPT Image 2.5 또는 GPT Image 2.6을 사용합니다. 실행 기록에는 실제로 제출한 프롬프트 전문과 언어, 제출 순서대로 정리한 참조 이미지, 기록 순서대로 정리한 원본 출력을 담습니다. 모델 식별자와 그 밖의 매개변수는 실행 기록에 있는 값을 표시합니다.

실제 출력을 살펴보고 눈으로 확인할 수 있는 특징과 재사용에 영향을 주는 한계를 기록합니다. 포스터나 스티커 시트에서는 문구를 순서대로 읽고, GIF는 프레임을 확인한 뒤 파일에서 재생 정보를 가져옵니다. 실행 날짜는 실행 기록에서 가져오고, 페이지 갱신 날짜는 마지막으로 내용을 편집한 날짜입니다.

[제품 스토리보드](prompt:p_123#run-x_168)와 [색상 변형](prompt:p_123#run-x_196)은 서로 다른 프롬프트를 사용했습니다. [시장 기회 슬라이드](prompt:p_217#run-x_281)는 중국어 원문으로 생성했으며 영어 번역도 제공합니다. [월요일 캐릭터 GIF](prompt:p_287#run-x_351)는 9프레임으로 이루어져 한 번 반복되는 데 2.4초가 걸립니다. GIF는 계속 반복 재생됩니다.
