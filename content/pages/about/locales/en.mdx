Prompt Seen is a library of image prompts you can read, copy and adapt. Every entry shows the image it produced and marks which phrases in the prompt changed what.

## How are prompts tested?

Each prompt is run with a recorded model, date and parameters. The record is kept with the prompt as an example run, and the page shows when it was last tested. Entries with no recorded run are marked “Not verified”.

## What are the sample entries?

The 101 content images were generated with GPT Image using the prompts shown on their pages. Each has a recorded run and a visual review. The built-in tool does not expose the exact model snapshot or usage. Downloadable full-size images may use a lossless format conversion; display sizes are compressed separately. The earlier procedural sample runs are archived.

## How do I report a problem?

Open an issue in the project's repository for wrong information, broken pages or a licensing concern.
