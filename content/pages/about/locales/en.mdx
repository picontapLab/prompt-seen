Prompt Seen is a library of image prompts and reusable templates with generated results.

## How are prompts tested?

Every case in the library uses GPT Image 2.5 or GPT Image 2.6. A run records the submitted prompt verbatim, its language, the reference images in submission order, and the original outputs in order. Model identifiers and other parameters appear when the run record includes them.

We review the actual output for visible details and record any limits that affect reuse. For text or sticker sheets, we read each label in order. For GIFs, we inspect the frames and report playback information from the file. The run date comes from the record and the page update date indicates the latest editorial change.

The [product storyboard](prompt:p_123#run-x_168) and its [color variant](prompt:p_123#run-x_196) use distinct submitted prompts. The [market-opportunity slide](prompt:p_217#run-x_281) was generated from Chinese and is available with an English translation. The [Monday character GIF](prompt:p_287#run-x_351) has nine frames and takes 2.4 seconds per loop. It loops continuously.
