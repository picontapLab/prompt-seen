Prompt Seen est une bibliothèque de prompts d’image que vous pouvez lire, copier et adapter. Chaque fiche montre l’image obtenue et indique quelles expressions du prompt ont influencé quels éléments.

## Comment les prompts sont-ils testés ?

Chaque prompt est exécuté avec un modèle d’IA, une date et des paramètres enregistrés. Ce compte rendu est conservé avec le prompt en tant qu’exemple d’exécution, et la page indique la date du dernier test. Les fiches sans exécution enregistrée portent la mention « Non vérifié ».

## Que sont les exemples proposés ?

Les 101 images de contenu ont été générées avec GPT Image à partir des prompts affichés sur leurs pages. Chacune dispose d’une exécution enregistrée et d’un examen visuel. L’outil intégré n’expose ni la version exacte du modèle ni les données d’utilisation. Les images téléchargeables en taille réelle peuvent avoir subi une conversion de format sans perte ; les formats d’affichage sont compressés séparément. Les anciennes exécutions d’exemple procédurales sont archivées.

## Comment signaler un problème ?

Ouvrez une issue dans le dépôt du projet pour signaler une information erronée, une page défectueuse ou une question de licence.
