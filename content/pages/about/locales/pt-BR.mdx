O Prompt Seen é uma biblioteca de prompts de imagem que você pode ler, copiar e adaptar. Cada item mostra a imagem produzida e indica quais frases do prompt alteraram quais aspectos do resultado.

## Como os prompts são testados?

Cada prompt é executado com modelo, data e parâmetros registrados. O registro fica junto ao prompt como uma execução de exemplo, e a página mostra quando ele foi testado pela última vez. Os itens sem execução registrada são marcados como “Não verificado”.

## O que são os exemplos de conteúdo?

As 101 imagens de conteúdo foram geradas com GPT Image usando os prompts exibidos nas respectivas páginas. Cada uma tem uma execução registrada e uma revisão visual. A ferramenta integrada não informa o snapshot exato do modelo nem os dados de uso. As imagens em tamanho original disponíveis para baixar podem passar por uma conversão de formato sem perdas; os tamanhos de exibição são comprimidos separadamente. As execuções anteriores de exemplos procedurais estão arquivadas.

## Como relato um problema?

Abra uma issue no repositório do projeto para informar dados incorretos, páginas com problemas ou dúvidas sobre licenciamento.
