## Code

Der Code der Website, ihre Skripte und Komponenten werden unter der MIT-Lizenz veröffentlicht.

## Prompts und Beschreibungen

Prompt-Texte und die Beschreibungen auf den einzelnen Seiten stehen unter [Creative Commons Namensnennung 4.0](https://creativecommons.org/licenses/by/4.0/). Du darfst sie unter Namensnennung und mit einem Link zur Seite weiterverwenden.

## Bilder

Bilder werden einzeln lizenziert; die jeweilige Bildseite nennt die Lizenz. Die mit GPT Image erzeugten Inhaltsbilder in diesem Repository stehen unter CC BY 4.0.

## Name und Logo

Der Name Prompt Seen und sein Logo fallen nicht unter diese Lizenzen.
