## 사용 방법

제품 사진 한 장을 업로드하고 팔레트와 장면 주제를 정확히 아홉 개 제공하세요.

모든 칸에서 제품 실루엣, 뚜껑과 라벨을 일관되게 유지하세요.

## 기록된 결과

이 템플릿에는 같은 합성 PINE 병 참조 이미지를 사용한 실행 예시 두 개가 기록되어 있습니다. 기본값은 세이지색, 아이보리색과 은색 캠페인에 제출한 텍스트를 만들고, 다른 예시 값은 차콜색, 호박색과 야외 장면을 사용합니다. [테스트한 캠페인 사례](prompt:p_123)에서 각 출력에서 관찰한 내용을 설명합니다.

## 생성 증거와 한계

[기본 실행](https://github.com/picontapLab/prompt-seen/blob/89395feb8e5fda7419aa3f5d2594df8a71fb3363/content/examples/x_168/run.yaml)과 [대안 실행](https://github.com/picontapLab/prompt-seen/blob/89395feb8e5fda7419aa3f5d2594df8a71fb3363/content/examples/x_196/run.yaml)은 2026년 10월 29일의 템플릿 v1, 제출한 값, 프롬프트 해시, 참조 ID와 출력 ID를 기록합니다. 해당 테스트 이미지에 표시된 제품 참조 이미지를 업로드하세요. 템플릿 필드는 입력 이미지가 아닌 텍스트를 바꿉니다.

GPT Image 2.5는 [프로젝트 소유자가 명시한 버전](https://github.com/picontapLab/prompt-seen/blob/89395feb8e5fda7419aa3f5d2594df8a71fb3363/production/model-version-annotation-2026-11-05.json)입니다. 내장 이미지 도구는 정확한 API 모델 ID를 반환하지 않았으며 시드, 샘플링과 품질 설정은 기록되지 않았습니다. 텍스트와 입력이 같아도 동일한 픽셀을 보장하지 않습니다.

필드를 수정하면 프롬프트가 만들어지며 새 이미지가 생성되는 것은 아닙니다. 일치하는 실행 기록이 없는 값은 아직 테스트하지 않은 상태입니다. 자신의 사진으로 생성한 뒤 아홉 칸 레이아웃, 라벨 글자와 제품 실루엣을 확인하세요.

## 영감

원본 출처와 관찰 날짜가 있는 반응 지표는 [테스트한 사례](prompt:p_123)를 참고하세요.
