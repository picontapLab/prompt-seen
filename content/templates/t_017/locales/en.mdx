## How to use

Upload one product photo; supply a palette and exactly nine scene themes.

Keep the product silhouette, cap and label consistent in every panel.

## Recorded result

This template has two recorded examples using the same synthetic PINE bottle reference. The default values produce the submitted text for the sage, ivory and silver campaign; the alternate values use charcoal, amber and outdoor scenes. The [tested campaign case](prompt:p_123) explains what was observed in each output.

## Generation evidence and limits

The [default run](https://github.com/picontapLab/prompt-seen/blob/89395feb8e5fda7419aa3f5d2594df8a71fb3363/content/examples/x_168/run.yaml) and [alternate run](https://github.com/picontapLab/prompt-seen/blob/89395feb8e5fda7419aa3f5d2594df8a71fb3363/content/examples/x_196/run.yaml) record template v1, submitted values, prompt hashes, reference IDs and output IDs on October 29, 2026. Upload the product reference shown with the matching test print; the template fields change the text, not the input image.

GPT Image 2.5 is the [project owner's version attribution](https://github.com/picontapLab/prompt-seen/blob/89395feb8e5fda7419aa3f5d2594df8a71fb3363/production/model-version-annotation-2026-11-05.json). The built-in image tool returned no exact API model ID, and no seed, sampling or quality settings were recorded. Matching the text and input does not guarantee identical pixels.

Editing fields creates a prompt, not a newly generated image. Values without a matching recorded run remain untested. Check the nine-panel layout, label text and product silhouette after generating with your own photo.
