## Como usar

Os valores padrão reproduzem o prompt exato usado para esta imagem. Edite os campos para criar uma nova variante. Mudar o elemento principal cria uma nova variante, ainda não testada. Este exemplo não usa imagem de referência.

## Resultado observado

Um livro aberto sustenta árvores de papel em camadas, uma casinha, uma raposa e uma ponte sobre um riacho. A textura do papel, as abas, as dobras e as sombras entre camadas estão visíveis.
