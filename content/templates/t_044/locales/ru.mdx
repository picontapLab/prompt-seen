## Как использовать

Значения по умолчанию воспроизводят точный промпт, использованный для этого изображения. Отредактируйте поля, чтобы создать новый вариант. Смена объекта создаёт новый, непроверенный вариант. В этом примере нет референсного изображения.

## Наблюдаемый результат

Банка зелёного чая занимает нижнюю часть кобальтового постера, оставляя верх свободным для последующего текста.

## Источник

Самостоятельная адаптация из предоставленной подборки дизайнерских промптов, пример 10. [Источник](https://pixonara.com/prompts/ai-product-photo-prompts). Изображение создано с GPT Image 2.5. Инструмент не вернул точный идентификатор модели API.
