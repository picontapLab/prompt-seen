## Como usar

Os valores padrão reproduzem o prompt exato usado para esta imagem. Edite os campos para criar uma nova variante. Mudar o elemento principal cria uma nova variante, ainda não testada. Envie as imagens sintéticas de referência mostradas na execução, na ordem indicada, antes de gerar.
