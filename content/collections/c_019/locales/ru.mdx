## Какие фотографии нужны для вашего товара

- Для украшений и изделий из стекла покажите блики, места соединений крупным планом и предмет для сравнения размеров.
- Для одежды и сумок покажите вещь в разложенном виде, швы, выбранный цвет и пример того, как её носят. Для изделий на заказ добавьте изображение надписи.
- Для электроники и инструментов покажите заднюю сторону, разъёмы, размеры и комплектующие. Работу подвижных деталей покажите по шагам.
- Для мебели и систем хранения покажите заднюю сторону, занимаемую площадь, измеренные габариты и вид в интерьере. Укажите, сколько места нужно для открывания.
- Для продуктов питания и подарочных наборов покажите внешнюю упаковку, количество единиц и содержимое после распаковки. Обязательная маркировка должна читаться на реальной фотографии.
- Для подержанной вещи в единственном экземпляре начните с исходной фотографии вещи целиком и добавьте отдельный крупный план каждого дефекта.

Проверьте правила Amazon США для белого фона, требования Google Merchant Center к метаданным IPTC и правила Etsy для реальных фото конкретной категории. На eBay используйте снимки именно продаваемой вещи и её дефектов.
