Chaque GIF contient neuf images encodées, assemblées localement à partir d’œuvres GPT Image archivées. Les sources à huit poses répartissent une pose maintenue sur deux images encodées ; les séquences plus longues sélectionnent neuf poses. Durée totale et réglages de boucle sont conservés. Ce sont des adaptations indépendantes, pas des sorties GIF natives ni des tests exacts des prompts originaux. Les petites cellules sources peuvent être agrandies sans ajout de détails. La langue originale du prompt est conservée. Voir aussi les [tests statiques originaux](collection:c_013).
