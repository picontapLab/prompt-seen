## Prompts statiques testés

Onze exemples acceptés utilisent les prompts complets des auteurs dans leur langue originale. Les images de référence sont générées pour ce projet. Le portrait de rue a réussi après nouvel essai ; quatre autres cas statiques restent rejetés par l’outil d’image.

Les auteurs attribuent leurs œuvres sources à Image 2.6. Ces onze exemples ont été générés avec GPT Image 2.6. L’outil n’a fourni aucun identifiant de modèle API exact. La liste suit les mentions J’aime des publications X d’origine observées le 7 novembre 2026 ; ce sont des instantanés de publications entières, pas l’engagement de nos exemples ni un classement entre plateformes.
