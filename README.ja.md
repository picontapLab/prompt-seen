# Prompt Seen

<p align="center"><img src="./src/app/icon.svg" alt="Prompt Seen ロゴ" width="88" /></p>

<p align="center"><strong>検証済みの AI 画像プロンプトと再利用できるテンプレート。</strong></p>

Prompt Seen は、プロンプト、テンプレート、実際の生成結果を検索できるライブラリです。視覚的なアイデアを再現可能な制作レシピへ変換できます。

## Prompt Seen の特徴

- 結果と正確なレシピを並べて確認できます。
- フレーズが構図、スタイル、被写体、レイアウトに与える影響を確認できます。
- プロンプトやテンプレートを新しい制作に再利用できます。
- カテゴリ、スタイル、用途、言語、コレクションから探せます。
- モデル、入力、出力、クレジット、ライセンスを記録します。
