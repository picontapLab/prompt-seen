## Prompt · Simplified Chinese

```text
依据输入照片和红色圈选标注，只把圈内陶瓷花瓶的釉色改成钴蓝色。保留花瓶的形状、反光、阴影和插花，不改变桌面、墙面及其他物件。最终成图移除红圈和所有标注，维持自然摄影质感。
```

## How to use

Use the exact recorded prompt and the displayed original reference assets in order. Changes to the prompt or inputs create an untested variant.

Upload the original synthetic room photo first and the separate red-circle markup overlay second. The overlay identifies the vase; it is not the generated result. The recorded working prompt is in Chinese and remains unchanged here. An English translation would be a new, untested prompt.

## Observed result

Vase changed from cream to cobalt blue, red markup removed. Jug, dried stems, tiles and window remain visually consistent; new glaze is glossier.
