Prompt · English
Using the uploaded product photo, design a 3-by-3 campaign contact sheet. Keep the container, label and brand palette consistent across all nine panels. Use this campaign palette: sage green, ivory and brushed silver. In reading order the nine panels show: hero shot; cap and label close-up; hand holding the bottle; brushed metal detail; three-bottle repeated arrangement; floating bottle; paint texture macro; bottle beside leaves; bottle on a picnic table. Use coherent lighting, even gutters and a 4:5 canvas.

How to use

Recorded result

This template has two recorded examples using the same synthetic PINE bottle reference. The default values produce the submitted text for the sage, ivory and silver campaign; the alternate values use charcoal, amber and outdoor scenes. The tested campaign case explains what was observed in each output.

Generation evidence and limits

The default run and alternate run record template v1, submitted values, prompt hashes, reference IDs and output IDs on October 29, 2026. Upload the product reference shown with the matching test print; the template fields change the text, not the input image.

GPT Image 2.5 is the project owner's version attribution. The built-in image tool returned no exact API model ID, and no seed, sampling or quality settings were recorded. Matching the text and input does not guarantee identical pixels.

Editing fields creates a prompt, not a newly generated image. Values without a matching recorded run remain untested. Check the nine-panel layout, label text and product silhouette after generating with your own photo.
